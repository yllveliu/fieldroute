# Sprint 1 — Foundation

Sprint goal
: Establish project monorepo foundation for local development.

KAN-1 task description
: Set up base monorepo, minimal FastAPI backend, minimal Vite React TypeScript frontend, PostgreSQL service, and Docker Compose configuration.

What this task sets up
:
- Project folders for `backend` and `frontend`
- Minimal FastAPI app with health check endpoint
- Minimal Vite + React TypeScript app
- `docker-compose.yml` wiring `api`, `frontend`, and `db` services
- `.env.example` with DB credentials and `DATABASE_URL`
